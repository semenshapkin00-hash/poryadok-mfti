# Порядок · SPN 0.4

Исследовательский прототип локального навигатора по регламентам. Он ищет подтверждённые действия и табличные факты, показывает исходные цитаты и сообщает, когда источников или условий недостаточно. Проверяемая цитата подтверждает происхождение текста, но сама по себе не доказывает полноту ответа или применимость нормы.

Публичная веб-демонстрация использует **только 13 вымышленных Markdown-документов и одну вымышленную Excel-книгу** из `demo/manifest.json`. Она не содержит внутренние материалы МФТИ. Загрузка пользовательских документов в этом режиме отключена, общая история ответов не публикуется. Для собственных документов предусмотрен отдельный локальный запуск.

## Возможности и ограничения

- TXT, Markdown, DOCX и текстовый PDF: извлечение пунктов с источниками. Учитываются явно заданные или надёжно извлечённые даты, роли и связи редакций; неизвестная применимость требует проверки.
- XLSX: листы, строки, адреса ячеек, буквальные значения, формулы и сохранённые результаты. Формулы не пересчитываются, внешние книги не открываются. Кэш формулы может быть устаревшим и помечается для сверки.
- Сканированные PDF, PNG и JPEG: локальный Tesseract OCR с координатами. Распознанные числа и условия требуют сверки с оригиналом; OCR не превращает изображение в достоверный нормативный источник.
- BM25 и локальный multilingual MiniLM используются для поиска. Отсутствие подтверждения приводит к отказу или уточнению. Возможны избыточные отказы, пропуски связей между документами и ошибки разбора вопроса.
- Источники и ответы локальной версии сохраняются в выбранном data-volume. После установки зависимостей и публичных весов обработка не требует облачного LLM/OCR API. Пользовательские документы не загружаются вместе с весами.

Это прототип, а не юридическая консультация и не готовая корпоративная система. В нём нет SSO, разграничения доступа по подразделениям, утверждённой политики хранения или гарантии правильного ответа. Синтетические тесты не являются оценкой точности на официальном корпусе или обещанием результата конкурса.

## Локальный запуск в Docker

Нужны Docker Engine и Compose v2+, 2 CPU, 2 ГиБ RAM контейнеру и место для сборки сверх сохраняемых 5 ГиБ свободного диска. До выполнения Linux CI сборка на вашей платформе считается непроверенной.

```sh
docker compose build app
docker compose --profile setup run --rm models-download
docker compose up -d app
```

Интерфейс: `http://127.0.0.1:8769`. При setup скачиваются только шесть открытых файлов с закреплёнными ревизиями и SHA-256. Никакие документы для этого не нужны. После setup приложение запускается с проверкой весов и без внешнего маршрута в Compose-сети.

```sh
curl --fail http://127.0.0.1:8769/api/health
docker compose exec app python tools/container_check.py --smoke
docker compose stop app
```

`--smoke` действительно выполняет MiniLM и OCR на синтетическом изображении; health проверяет лишь доступность компонентов. `docker compose down` сохраняет данные. Команда с `-v` удаляет volumes и не нужна для обычной остановки.

Полная инструкция, установка весов без сети и ограничения публичного размещения: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Проверка публичной сборки

`PUBLIC_RELEASE_MANIFEST.json` перечисляет каждый разрешённый файл и его SHA-256. В публичном дереве отсутствуют рабочая база, внутренние документы, `reference`, `experiments`, секреты, `.env` и сами веса. Публикуется проверенный отдельный снимок исходников, а не вся рабочая директория.

Linux CI на стандартном `ubuntu-24.04` проверяет снимок, собирает Docker target `space`, запускает контейнер, health и фактический MiniLM/OCR smoke, затем выполняет выбранные синтетические тесты XLSX, метаданных и изоляции демо. Логи и JSON/XML-подтверждения сохраняются как CI artifact. Наличие workflow без успешного запуска не считается доказательством работоспособности. Платные runners и пользовательские секреты не требуются.

Публичные веса MiniLM и Tesseract распространяются их авторами по Apache-2.0; ссылки на закреплённые источники находятся в `tools/container_models.py`. Веса не входят в исходный репозиторий.
