# Сторонние компоненты публичного снимка

[THIRD_PARTY.md](../THIRD_PARTY.md) перенесён из рабочего проекта без изменения авторства и условий. Он описывает проект шире публичного демо. Этот снимок не назначает MIT, Apache или другую общую лицензию собственному коду команды SPN; права и условия сторонних авторов сохраняются отдельно.

Упаковщик копирует только явно перечисленные существующие тексты из `licenses/`, побайтно и с SHA-256 в `PUBLIC_RELEASE_MANIFEST.json`:

- FastAPI, Uvicorn, Pydantic, python-multipart, python-docx, pdfplumber, Pillow и pypdf. Последний входит в закреплённые зависимости для тестов.
- NumPy вместе с имеющимися текстами лицензий включённых компонентов.
- pymorphy3, список его авторов, dawg2-python и описание пакета словарей. Неизменённые словарные данные OpenCorpora устанавливаются отдельно; их CC BY-SA 3.0 не переобозначается лицензией приложения.
- Tesseract.js и Tesseract.js-core. Для core сохранена одна из двух побайтно одинаковых копий Apache-2.0.
- Имеющееся уведомление Ubuntu Font Licence 1.0 относится к тестовым PDF большого рабочего проекта; публичный демо-корпус состоит из Markdown и XLSX, шрифтовой файл в него не включён.

Это перечень сохранённых локальных уведомлений, а не утверждение о полном аудите всех транзитивных зависимостей. Версии Python закреплены в `requirements-lock.txt`, дерево Node — в `pnpm-lock.yaml`; лицензии и notices самих устанавливаемых пакетов должны сохраняться вместе с ними. Тексты для неиспользуемых здесь openpyxl, scipy и rapidfuzz не переносятся.

В репозитории нет весов, локальных model-manifest, словарных массивов, пользовательских документов или экспериментальных Qwen/MLX-артефактов. Публичные MiniLM и Tesseract устанавливаются отдельной явной командой из закреплённых источников; ссылки, ревизии и проверка SHA находятся в `tools/container_models.py`. Упоминание изолированного исследования Qwen в общем `THIRD_PARTY.md` не означает его включение в демо.
